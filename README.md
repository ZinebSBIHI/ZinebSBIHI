## Analysis pipelines

- [immune-repertoire-pipelines](https://github.com/ZinebSBIHI/immune-repertoire-pipelines): `immunerepertoire`, the R package shared by the three pipelines
- [bulk-repertoire-pipeline](https://github.com/ZinebSBIHI/bulk-repertoire-pipeline): bulk TCR and BCR repertoires (AIRR files from MiXCR or IgBLAST)
- [single-cell-repertoire-pipeline](https://github.com/ZinebSBIHI/single-cell-repertoire-pipeline): single-cell TCR and BCR repertoires, joined to the transcriptome
- [single-cell-gex-pipeline](https://github.com/ZinebSBIHI/single-cell-gex-pipeline): single-cell gene expression with Seurat v5

Each pipeline is driven by one configuration file, runs end to end on public or simulated example data, and records its parameters and package versions beside its results.
